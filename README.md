# 洗滌廠 3D 設備地圖

第一版原型：iPad / iPhone 友善的 3D 設備地圖。

## 已包含
- 3D 等角設備模型
- 編輯模式：點選後拖曳設備
- 巡檢模式：點設備查看設備資料
- 雙指縮放／旋轉視角（Three.js OrbitControls）
- 設備庫：點一下即可新增設備
- 搜尋、分類
- 初始設備位置
- 位置儲存在瀏覽器 localStorage
- 無工廠外框、無門、可向外持續增加設備
