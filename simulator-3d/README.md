# 設備監控台模擬器

獨立預覽頁，不修改正式設備管理系統，也不連線 NAS。

設備名稱、編號、分類、kind、x / y / z、旋轉、樓層與平面圖熱區，沿用正式頁內建配置（與資料庫欄位 `x`、`z`、`rotation_y` 以及地圖熱區相同形狀）。高度 y 在正式資料庫沒有獨立欄位，沿用正式頁配置裡的 0（一樓）、36（架高）、76（天車）。運轉狀態、查檢標記、清潔保養日期與維修備註是這份模擬器裡的示範值，用來預覽監控台配色。

場景把平面座標乘上 0.05，讓廠區放進鏡頭；y=36 畫在架高平台，y=76 畫在天車軌。

## 開啟

用瀏覽器直接打開 `index.html`（桌面版 Chrome、Edge 或 Firefox）。

或在此資料夾執行：

```sh
python3 -m http.server 8765
```

然後打開 http://127.0.0.1:8765/

操作：左鍵拖曳可水平環視 360°、滾輪縮放、右鍵平移、點設備會亮起並把鏡頭移過去。側邊「需關注」清單同樣可以點選。垂直角度從俯視到接近平視，避免鏡頭穿進地板。

畫面右上角標示「獨立模擬 · 未連接正式系統」。

## 重新打包

預覽用的 `app.js` 已附在資料夾內。若改了 `src/`，在此資料夾執行：

```sh
npm ci
npm run check
npm run build
```

3D 引擎為 [Three.js](https://github.com/mrdoob/three.js)（MIT）。
